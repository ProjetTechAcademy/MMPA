PAÏA by MMPA — CORRECTION DU DÉPLOIEMENT VERCEL
================================================

ERREUR CORRIGÉE
----------------
L’ancien paquet lançait Vinext/Vite et importait le fichier
.openai/hosting.json. Ce fichier appartient à l’environnement d’aperçu et
n’était pas présent dans GitHub, d’où l’erreur « Module introuvable ».

CORRECTION APPLIQUÉE
--------------------
- construction native Next.js : npm run build exécute maintenant next build ;
- suppression des dépendances de déploiement Vinext, Vite, Wrangler et
  Cloudflare ;
- aucun fichier .openai/hosting.json n’est requis ;
- le fichier tsconfig.json limite désormais la vérification TypeScript au site
  Next.js : même si Finder laisse d’anciens dossiers Vinext dans le dépôt, ils
  ne bloquent plus la compilation Vercel ;
- conservation intégrale des pages, styles, interactions, logos et visuels
  officiels de la version 9/10 ;
- compilation de production vérifiée une première fois sur le projet propre,
  puis une seconde fois en présence des anciens fichiers résiduels.

CE QU’IL FAUT FAIRE AVEC GITHUB DESKTOP
---------------------------------------
1. Décompresser le ZIP.
2. Ouvrir le dépôt local MMPA dans GitHub Desktop.
3. Remplacer l’ancien contenu du dépôt par TOUT le contenu du dossier
   décompressé. Ne pas déposer le ZIP lui-même dans GitHub.
4. Les dossiers app et public doivent être visibles à côté de package.json.
5. Il est préférable de supprimer vite.config.ts et les anciens dossiers
   .openai, worker, build, db, drizzle et examples, mais cette version compile
   aussi s’ils sont encore présents.
6. Commit : « Correction du build Next.js pour Vercel ».
7. Push origin.

VERCEL
------
Le push doit déclencher un nouveau déploiement. Vercel doit afficher :
- Framework Preset : Next.js ;
- Root Directory : ./ (ou vide) ;
- Build Command : next build / valeur détectée automatiquement ;
- Output Directory : valeur détectée automatiquement ;
- Install Command : npm install / valeur détectée automatiquement.

Ne renseigner ni .openai/hosting.json, ni D1, ni Wrangler dans Vercel.
